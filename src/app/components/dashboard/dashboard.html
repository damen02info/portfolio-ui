Deploy Lab: Demostración de despligue

Importante: Nada de esta demostración es una simulación. Todo se despliega, modifica y ejecuta sobre entornos reales en producción.

He diseñado este laboratorio interactivo para mostrar cómo se conectan el desarrollo y la infraestructura en un entorno real. Al interactuar con el panel, disparas un job real en Jenkins que modificará la estética de este portfolio de forma efímera. Tanto los logs como la tabla PostgreSQL están conectados en tiempo real.

1. Disparo Asíncrono: Al elegir un color, la interfaz en Angular bloquea preventivamente las acciones mediante Signals. En el backend, Spring Boot delega la carga pesada de forma asíncrona (@Async) llamando a la API de Jenkins para no bloquear al usuario.
2. Escucha de Logs en Tiempo Real: Jenkins ejecuta el pipeline que actualiza la configuración en PostgreSQL. El backend se conecta en directo al servidor para capturar estas trazas y transmitirlas al instante a tu terminal mediante un canal de Server-Sent Events (SSE).
3. Monitorización de BD y Rollback: Al finalizar, el portfolio cambia de color de forma reactiva. Un hilo en Java inicia un contador de destrucción; puedes monitorizar en tiempo real en la tabla de arriba cómo varían los registros de la base de datos hasta que el entorno expira y vuelve al estado original.
